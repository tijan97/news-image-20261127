A newspaper front page — "THE WORLD IN ONE DAY" — that sums up Friday 27 November 2026 world news in a single image. The lead story is the Iranian drone strike on Kuwait that killed two Italian workers, followed by Gaza, UK migration, North Korea, the Bangkok refinery fire, the Ibiza tanker capsize, and the Thanksgiving storm that postponed the Macy's parade, plus Black Friday, chess, tennis, and Ebola briefs. `main.py` (stdlib only, deterministic) copies the rendered `entry.png` to the output directory.

## Run it

```sh
python3 main.py
```

`gen_image.py` regenerates `entry.png` from scratch with Pillow.
